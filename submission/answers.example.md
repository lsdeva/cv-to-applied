# Application Answers Bank (template)

`/start` copies this file to `submission/answers.md` (gitignored, stays on your laptop) and fills in
what it can from your CV. `/submit` reads it to fill forms and adds every new answer you give under
"Learned answers", so each form gets faster. `ASK` means "ask me each time".

Matching rule: match on meaning, not exact wording ("When can you start?" = "Notice period"). If a
form's options don't include the approved answer, pick the closest one and record it.
