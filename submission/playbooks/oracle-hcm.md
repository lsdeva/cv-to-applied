# Oracle Recruiting Cloud (oraclecloud.com/hcmUI/CandidateExperience)

- Account needed: no password. Email + one-time verification code
- Typical flow: job -> APPLY NOW -> email + "I agree with the terms and conditions" -> NEXT -> "Confirm Your Identity" code screen -> application form.
